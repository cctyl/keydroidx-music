KeydroidX 音乐 - 主界面优化预览 (方案 A)

优化说明 新增第 5 个 Tab【设置】，每个 Tab 占 48dp，完美适配 240dp 视口。

⚡ 现有入口 100% 忠实保留，功能与行为完全一致：

  • 登录网易云 / 退出登录：未登录点击唤出 WebView 登录；已登录点击退出登录。
  • 网易云 Cookie 设置：进入 Cookie 设置页（扫码/手动导入）。
  • 后台播放：退至后台，保持音频播放。
  • 意见反馈：进入反馈界面提交 Issue 与日志。
  • 详细日志：开/关：一键开关分级详细日志落盘。
  • 关于：展示版本号与致谢。
  • 退出应用：停止 PlaybackService 并结束任务。

💡 提示：可用键盘 ← → 切 Tab，↑ ↓ 移焦点，Enter 确定，L 左软键。
