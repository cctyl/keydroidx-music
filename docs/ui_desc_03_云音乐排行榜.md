# 页面描述：KeydroidX Music — 云音乐排行榜页（榜单 Tab）

> 📌 **注**：本文档为原型视觉描述（含原型示意数值）。Android Native 实际落地规范以 **`UI_DESIGN_SPEC.md`** 为准，排版字号统一采用 `keydroidx-core` 的 **`11-typography-and-font-spec.md`** 6 级 `@dimen/nokia_font_*` 语义 Token。

---

## 一、整体布局层级

页面竖向全屏布局，从上到下三个固定层：

```
┌──────────────────────────────┐  ← 顶部标题栏 (TitleBar)，固定高度 28dp
├──────────────────────────────┤
│  ┌────────────────────────┐  │
│  │  横向 Tab 导航栏 (4项) │  │  ← 紧贴内容区顶部，固定
│  └────────────────────────┘  │
│                              │
│  内容区域 (可滚动列表)         │  ← 全部为榜单列表，每项高度 44dp
│                              │
└──────────────────────────────┘  ← 底部软键栏 (SoftKeyBar)，固定高度 26dp
```

---

## 二、各层详细描述

---

### 层 1：顶部标题栏（TitleBar）

- **位置**：屏幕最顶部，固定不滚动
- **背景**：从深蓝色渐变到藏青色（上浅下深线性渐变）
- **高度**：约 28dp

  **左侧（标题区）：**
  - Material Icon 图标：`leaderboard`（柱状图/排行），字号 14px，白色
  - 文字标题：**"云音乐排行榜"**，白色，粗体，字号 13px
  - 图标与文字水平对齐，间距 4px

  **右侧（状态区）：**
  - 信号图标：`signal_cellular_4_bar`（四格满格），灰白色，12px
  - 电量文字：**"70%"**，灰白色，11px

- **底部边缘**：1px 深黑细线

---

### 层 2：横向 Tab 导航栏（Tab Bar）

- **位置**：紧贴标题栏下方，固定
- **背景**：几乎纯黑（`#0a0e17`）
- **底部边缘**：2px 深蓝色横线
- **4 个等宽 Tab，从左到右：**

  | 顺序 | 图标 | 文字 | 状态 |
  |------|------|------|------|
  | 1 | `person` | 我的 | 未激活 |
  | 2 | `explore` | 发现 | 未激活 |
  | 3 | `leaderboard` | 榜单 | **当前激活（Active）** |
  | 4 | `search` | 搜索 | 未激活 |

  **激活 Tab（"榜单"）的视觉样式：**
  - 文字白色，粗体
  - Tab 背景有蓝色半透明渐变遮罩（约 40% 透明度）
  - Tab 底部有 2px 高、宽度 80% 的天蓝色（`#38bdf8`）高亮横线，居中

  **未激活 Tab：**
  - 图标与文字均为中灰色（`#b0b0b0`），无背景无底线

  每个 Tab：图标在上，文字在下；图标 13px，文字 11px

---

### 层 3：内容滚动区（Content Area）

- **背景色**：深暗色（`#141824`，暗蓝灰）

- **内容全部为榜单列表，共 4 行，每行高度 44dp**（比标准列表项高 8dp，因为需要展示两行文字）

## 五、焦点交互状态说明

- **焦点行（Focused Item）** 视觉变化：
  - 整行背景填充为主题焦点色（`#0055aa`）
  - 左右两侧各缩进 3px，圆角 4px
  - 底部虚线分割消失
  - 所有文字变为白色或极浅蓝白（`#e0f2fe`）
  - 缩略图保持原有彩色背景不变（色彩标识保留）
- **非焦点行**：正常样式，无背景色，底部有虚线分割
- **右侧箭头**：所有行均有 `chevron_right`，表示可进入查看榜单详情
