# 页面描述：KeydroidX Music — 音乐库主页（我的 Tab）

---

## 一、整体布局层级

页面是一个竖向全屏布局，从上到下分为三个固定层：

```
┌──────────────────────────────┐  ← 顶部标题栏 (TitleBar)，固定高度 28dp
├──────────────────────────────┤
│  ┌────────────────────────┐  │
│  │  横向 Tab 导航栏 (4项) │  │  ← 紧贴内容区顶部，固定
│  └────────────────────────┘  │
│                              │
│  内容区域 (可滚动列表)         │  ← 占据中间全部剩余空间
│                              │
└──────────────────────────────┘  ← 底部软键栏 (SoftKeyBar)，固定高度 26dp
```

---

## 二、各层详细描述

---

### 层 1：顶部标题栏（TitleBar）

- **位置**：屏幕最顶部，固定不滚动
- **背景**：从深蓝色渐变到更深的藏青色（上浅下深的线性渐变）
- **高度**：约 28dp
- **内部分为左右两区：**

  **左侧（标题区）：**
  - 一个 Material Icon 图标：`library_music`（堆叠音符/书本音符），字号 14px
  - 紧跟图标右侧，文字标题：**"我的音乐库"**，白色，粗体，字号 13px
  - 图标与文字水平居中对齐，中间留 4px 间距

  **右侧（状态区）：**
  - 信号图标：`signal_cellular_4_bar`（四格满格信号条），灰白色，字号 12px
  - 电量文字：**"70%"**，灰白色，字号 11px
  - 图标与文字之间留 3px 间距

- **底部边缘**：有一条极细的深黑色描边（1px）

---

### 层 2：横向 Tab 导航栏（Tab Bar）

- **位置**：紧贴标题栏下方，固定不随内容滚动
- **背景**：几乎纯黑（`#0a0e17`）
- **底部边缘**：有 2px 宽的深蓝色横线（主题色）
- **总共 4 个等宽 Tab，从左到右排列：**

  | 顺序 | 图标（Material Icons） | 文字 | 状态 |
  |------|----------------------|------|------|
  | 1 | `person`（人形轮廓） | 我的 | **当前激活（Active）** |
  | 2 | `explore`（探索/指南针） | 发现 | 未激活 |
  | 3 | `leaderboard`（柱状图） | 榜单 | 未激活 |
  | 4 | `search`（放大镜） | 搜索 | 未激活 |

  **激活 Tab（"我的"）的视觉样式：**
  - 文字为白色，粗体
  - Tab 背景有蓝色半透明渐变遮罩（从透明渐变到主题蓝色，约 40% 透明度）
  - Tab 底部有一条 2px 高、占 Tab 宽度 80% 的天蓝色（`#38bdf8`）高亮横线，居中对齐

  **未激活 Tab 的视觉样式：**
  - 图标和文字均为中灰色（`#b0b0b0`）
  - 无背景、无底部横线

  每个 Tab 内部：图标在上，文字在下，垂直排列居中；图标 13px，文字 11px

## 三、全局视觉风格

| 属性 | 值 |
|------|----|
| 主背景色 | `#141824`（暗蓝灰） |
| 标题栏/软键栏背景 | `#1a3a6b` → `#0d1b3e` 渐变 |
| 焦点高亮色 | `#0055aa`（中深蓝） |
| 强调色/图标色 | `#38bdf8`（天蓝色） |
| 主文字色 | `#ffffff`（白） |
| 副文字/次要色 | `#b0b0b0`（灰） |
| 分隔头文字色 | `#93c5fd`（浅蓝） |
| 列表虚线分割色 | `#2d426b`（深蓝灰） |
| 字体风格 | 点阵/等宽风格（DotGothic16 / Courier New 回退） |
| 图标规范 | 全部使用 Material Icons 矢量字体图标 |
| 圆角 | 仅焦点行有 4px 圆角，其余无圆角 |

## 四、焦点交互状态说明

- **焦点行（Focused Item）** 视觉变化：
  - 整行背景填充为主题焦点色（`#0055aa`）
  - 左右两侧各缩进 3px（行宽度减少 6px，产生"凸起"视觉）
  - 内边距相应调整（padding 从 8px 变 5px）
  - 底部虚线分割消失（`border-bottom: transparent`）
  - 所有子文字颜色统一变为白色或极浅蓝白（`#e0f2fe`）
  - Badge 颜色反转（白底蓝字）
- **非焦点行**：按正常样式呈现，无背景色，底部有虚线分割
