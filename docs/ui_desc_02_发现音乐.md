# 页面描述：KeydroidX Music — 发现音乐页（发现 Tab）

---

## 一、整体布局层级

页面竖向全屏布局，从上到下三个固定层：

```
┌──────────────────────────────┐  ← 顶部标题栏 (TitleBar)，固定高度 28dp
├──────────────────────────────┤
│  ┌────────────────────────┐  │
│  │  横向 Tab 导航栏 (4项) │  │  ← 紧贴内容区顶部，固定
│  └────────────────────────┘  │
│                              │
│  内容区域 (可滚动)            │  ← 上半段：2×2 宫格；下半段：今日推荐歌单列表
│                              │
└──────────────────────────────┘  ← 底部软键栏 (SoftKeyBar)，固定高度 26dp
```

---

## 二、各层详细描述

---

### 层 1：顶部标题栏（TitleBar）

- **位置**：屏幕最顶部，固定不滚动
- **背景**：从深蓝色渐变到藏青色（上浅下深线性渐变）
- **高度**：约 28dp

  **左侧（标题区）：**
  - Material Icon 图标：`explore`（指南针/探索），字号 14px，白色
  - 文字标题：**"发现音乐"**，白色，粗体，字号 13px
  - 图标与文字水平对齐，间距 4px

  **右侧（状态区）：**
  - 信号图标：`signal_cellular_4_bar`（四格满格），灰白色，12px
  - 电量文字：**"70%"**，灰白色，11px

- **底部边缘**：1px 深黑细线

---

### 层 2：横向 Tab 导航栏（Tab Bar）

- **位置**：紧贴标题栏下方，固定
- **背景**：几乎纯黑（`#0a0e17`）
- **底部边缘**：2px 深蓝色横线
- **4 个等宽 Tab，从左到右：**

  | 顺序 | 图标 | 文字 | 状态 |
  |------|------|------|------|
  | 1 | `person` | 我的 | 未激活 |
  | 2 | `explore` | 发现 | **当前激活（Active）** |
  | 3 | `leaderboard` | 榜单 | 未激活 |
  | 4 | `search` | 搜索 | 未激活 |

  **激活 Tab（"发现"）的视觉样式：**
  - 文字白色，粗体
  - Tab 背景有蓝色半透明渐变遮罩（约 40% 透明度）
  - Tab 底部有 2px 高、宽度 80% 的天蓝色（`#38bdf8`）高亮横线，居中

  **未激活 Tab：**
  - 图标与文字均为中灰色（`#b0b0b0`），无背景无底线

  每个 Tab：图标在上，文字在下；图标 13px，文字 11px

## 三、全局视觉风格

| 属性 | 值 |
|------|----|
| 主背景色 | `#141824`（暗蓝灰） |
| 标题栏/软键栏背景 | `#1a3a6b` → `#0d1b3e` 渐变 |
| 焦点高亮色 | `#0055aa`（中深蓝） |
| 强调色/图标色 | `#38bdf8`（天蓝色） |
| 宫格卡片背景 | `#182234` → `#0f1624` 渐变 |
| 宫格卡片边框 | `#233454`（深蓝灰） |
| 主文字色 | `#ffffff`（白） |
| 副文字色 | `#b0b0b0`（灰） |
| 分隔头文字色 | `#93c5fd`（浅蓝） |
| 图标规范 | 全部使用 Material Icons 矢量字体图标 |
| 圆角 | 宫格卡片 4px；焦点列表行 4px；其余无圆角 |

## 四、焦点交互状态说明

- **宫格卡片焦点状态：**
  - 背景变为主题蓝（`#0055aa`）
  - 边框变为浅蓝白（`#93c5fd`）
  - 图标变为纯白色
  - 副标题文字变为极浅蓝白（`#e0f2fe`）
- **列表项焦点状态：**
  - 整行背景变为主题蓝，左右缩进 3px，圆角 4px
  - 底部虚线消失
  - 所有文字变白或极浅蓝白
- **非焦点项：** 正常样式，无背景色，底部有虚线
