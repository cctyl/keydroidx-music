## 一、 设计哲学与生态规范

1. **纯物理按键驱动 (Key-Driven First)**：
   - 界面所有元素必须完全可通过 D-Pad 方向键（`UP`/`DOWN`/`LEFT`/`RIGHT`）、确定键（`SELECT`/`DPAD_CENTER`）、双软键（`SOFT_LEFT`/`SOFT_RIGHT`）及特定快捷键（`*`、`#`、`数字键`）操作。
   - 严禁设计依赖触屏滑动、长按拖拽等仅限触屏的交互方式。

2. **零二次配置与主题热换肤**：
   - 继承 `NokiaBaseActivity`，通过 `NokiaKeyProvider` 自动同步 Launcher 端的物理按键映射、全局主题配色和像素点阵字体（ArkPixel / FusionPixel）。
   - 颜色与背景必须使用 `NokiaTheme` 动态着色，严禁硬编码颜色值。

3. **三级平滑降级**：
   - 第一级：KeydroidX Launcher 广播与 ContentProvider 统一键值。
   - 第二级：音乐 App 本地 SharedPreferences 独立键位配置。
   - 第三级：Android 官方标准键码回退兜底。

## 二、 界面整体架构与布局系统

页面统一采用“**三段式诺基亚经典骨架**”：

```
┌────────────────────────────────────────────────────────────┐  ▲ 28dp
│ 顶部标题栏 (Top TitleBar: 图标 + 页面标题/滚动曲名 + 状态指示) │  │
├────────────────────────────────────────────────────────────┤  ▼
│                                                            │
│                                                            │
│                   主内容视口区 (Content View)               │
│                                                            │
│   - 列表项标准高度: 36dp (双行文字: 标题 11dp + 副标题 9dp) │
│   - 宫格项标准尺寸: 2x2 Grid (高度 48dp)                   │
│   - 焦点状态: 带主题主色高亮边框、背景半透叠加、文字反白     │
│                                                            │
│                                                            │
├────────────────────────────────────────────────────────────┤  ▲ 24dp
│ 底部软键栏 (SoftKeyBar: 左软键[选项] | 中确定 | 右软键[返回])│  │
└────────────────────────────────────────────────────────────┘  ▼
```

### 1. 顶部标题栏 (`Top TitleBar` - 28dp)
- **左侧**：当前页面图标（MaterialIcons 矢量字），如 `queue_music`、`play_circle_filled`。
- **中间**：页面标题文字（如 `原键音乐`、`我喜欢的音乐`、`正在播放`），播放状态下可跑马灯滚动当前曲目。
- **右侧**：微型状态标签（如后台播放动态波形、歌单总曲数等）。

### 2. 底部软键栏 (`SoftKeyBar` - 24dp)
- 严格遵循 Nokia S40 / S60 三段式对称布局：
  - **左软键 (Soft Left)**：呼出上下文相关菜单（文本一般为 `选项`）。
  - **中确定 (Soft Center)**：当前焦点的主操作提示（如 `选择`、`播放`、`确定`、`暂停`）。
  - **右软键 (Soft Right)**：返回上一层级或退出（文本一般为 `返回`、`退出`）。

## 四、 核心页面视觉与业务逻辑

### 4.1 主界面 (MainActivity - 四 Tab 体系)

主界面由顶部 Tab 分页与下方列表/宫格构成：

#### Tab 0: 【我的】(Personal Library)
- **数据结构与入口**：
  1. `我喜欢的音乐`（红心图标，显示歌曲总数，如 496 首）
  2. `最近播放历史`（历史图标，如 100 首）
  3. `本地音乐扫描`（文件夹图标，展示扫描到的本地无损/MP3）
  4. 分割线：`创建与收藏的歌单`
  5. 歌单列表条目（歌单名 + 曲数）
- **操作逻辑**：
  - `OK` 键：进入对应的歌单详情歌曲列表页；
  - `左软键`：呼出选项菜单（包含：新建歌单、导入歌单、本地重新扫描、刷新云端、外观主题设置）。

#### Tab 1: 【发现】(Explore & FM)
- **顶部 2x2 快捷方块**：
  - `[0,0] 私人FM` (电台心动流，直接进入 FM 播放模式)
  - `[0,1] 每日推荐` (日历图标，显示今日日期，进入日推歌曲列表)
  - `[1,0] 歌单广场` (精选推荐分类与网友歌单)
  - `[1,1] 排行榜` (官方云音乐各大榜单)
- **下方推荐列表**：
  - 精选推荐歌单卡片（缩略图/点阵标识 + 歌单标题 + 播放量）。
- **操作逻辑**：
  - 上下左右键在 2x2 方块与下方列表间无缝游走，`OK` 键触发进入。

#### Tab 2: 【榜单】(Top Charts)
- **榜单列表**：
  - 官方榜单条目：`飙升榜`、`新歌榜`、`原创榜`、`热歌榜`、`赞赏榜` 等。
  - 每行显示：榜单名、更新频率（如“刚刚更新”、“每周四更新”）、Top 1 代表曲目。
- **操作逻辑**：
  - `OK` 键：直接加载并打开该排行榜的歌曲列表。

#### Tab 3: 【搜索】(Search)
- **界面元素**：
  - 顶部输入框：带有像素光标的搜索框，支持实体按键输入。
  - 中部热搜词流：高频热搜歌曲/歌手。
  - 下部搜索历史列表：按时间倒序排列的历史搜索词，附带删除单条/清空全部选项。
- **操作逻辑**：
  - 焦点在历史或热搜词上按 `OK`，自动填入并执行网络搜索；
  - 搜索结果以歌曲列表呈现。

---

### 4.2 歌单与歌曲列表页 (PlaylistActivity / Detail)

- **顶部常驻快捷操作栏**：
  - `播放全部歌曲`（带绿色播放图标，显示总曲数与当前播放模式）。
- **歌曲列表项规格 (36dp 行高)**：
  - **左侧**：歌曲序号（01, 02...）；
  - **中间**：歌曲名（单行超长跑马灯） + 歌手名（浅灰小字）；
  - **动态指示器**：当前正在播放的曲目，其标题右侧闪烁 `volume_up` 动态波形图标；
  - **右侧**：红心喜欢标记（实心红心/空心线框）。
- **按键操作**：
  - 焦点在某首歌按 `OK`：将当前列表设为播放队列，立即播放该曲并进入播放详情页；
  - 按 `左软键`：呼出歌曲专属菜单（下一首播放、收藏到歌单、查看专辑/歌手、下载、分享）。

---

### 4.3 正在播放详情页 (MusicPlayerActivity)

专为复古机型定制的音乐唱机界面：

1. **黑胶唱片旋转动效区 (Vinyl Record Area)**：
   - 居中拟真黑胶唱片，带有唱针与中心微缩封面；
   - 播放状态下匀速平滑旋转，暂停时平滑减速静止。
2. **歌曲信息区**：
   - 歌曲主标题（12dp 粗体点阵字）+ 歌手/专辑（10dp 浅色点阵字）。
3. **单行动态歌词条 (Lyric Floating Bar)**：
   - 实时随播放进度更新当前句歌词；
   - 右侧常驻提示标签：`[按 * 全屏]`；
   - 允许光标选中点击或按 `*` 展开。
4. **高精度像素进度条 (Progress Bar)**：
   - 细线槽位 + 主题色填充条；
   - 左右两端标明 `当前播放时间 (01:23)` 与 `音频总时长 (04:15)`。
5. **常驻屏幕按键指引栏 (Controls Guide - 5格)**：
   - `[← 上曲]` | `[→ 下曲]` | `[* 歌词]` (高亮黄) | `[# 模式]` (高亮黄) | `[左软:选项]`。
6. **核心交互**：
   - `OK`：播放 / 暂停；
   - `LEFT` / `RIGHT`：上一首 / 下一首；
   - `UP` / `DOWN`：音量调节；
   - `*` 键：展开全屏歌词；
   - `#` 键：切换播放模式（并在屏幕弹出醒目 Toast 提示当前为：列表循环/单曲循环/随机播放）。

---

### 4.4 全屏歌词滚屏页 (LyricFullView / LyricActivity)

- **界面呈现**：
  - 完整呈现 LRC 逐行歌词，纵向居中排列；
  - **当前播放行**：大号字体加粗（13dp）、高亮主题色，背景带有像素半透明选中条；
  - **非播放行**：次级浅色字体（11dp）。
- **按键互动**：
  - 按 `UP` / `DOWN`：自由上下滚动光标浏览上下文歌词；
  - 按 `OK` (回正进度)：音乐播放时间立即 Seek 调整至用户当前光标浏览的歌词时间点；
  - 按 `*` 键 或 `右软键` (返回播放)：退出歌词视图，返回黑胶唱片播放页。

### 4.5 标准选项菜单 (NokiaOptionsDialog)

当用户在任意界面按下 `SOFT_LEFT` (左软键) 时，自底部升起标准的诺基亚选项对话框：

- **列表项规范**：
  - 每行带有：数字序号 (1-9)、MaterialIcons 矢量图标、功能文案；
  - 用户既可以通过 `UP`/`DOWN` + `OK` 选取，也可以直接按下键盘对应的 **`1` ~ `9` 数字键直达触发**。
- **典型菜单配置**：
  - **主页选项**：`1. 刷新列表`、`2. 播放选中`、`3. 切换主题配色`、`4. 本地音乐扫描`、`5. 退出程序`。
  - **播放页选项**：`1. 全屏歌词浏览`、`2. 切换播放模式`、`3. 红心喜欢/取消`、`4. 查看歌曲详情`、`5. 播放列表`、`6. 返回主菜单`。

### 2. 字体与图标标准
- **排版字号**：统一使用 `keydroidx-core` 规范的 6 级 `@dimen/nokia_font_*` 语义 Token（`display:16sp`, `title:13sp`, `body:12sp`, `small_title:11sp`, `caption:9sp`, `micro:7sp`），禁止在 XML 中裸写字号数字。
- **字体**：全部采用 `ArkPixel` (方舟像素点阵体) 或 `FusionPixel`，通过 `NokiaBaseActivity` 全局递归注入。
- **图标**：一律使用 `keydroidx-core` 内置的 `NokiaIcons` (MaterialIcons 矢量字体编码)，禁止引入第三方位图 PNG 以确保极佳的 240dp 锐利度。

## 六、 组件映射与代码实现指南

在后续 Android Native 开发阶段，各层代码结构映射如下：

```
io.github.cctyl.keydroidx.music/
├── ui/
│   ├── MainActivity.kt               # 继承 NokiaBaseActivity，管理 4 个 Tab Fragment / ViewPager
│   ├── MusicPlayerActivity.kt        # 正在播放详情 Activity (黑胶动效 + 进度条 + 快捷提示)
│   ├── LyricActivity.kt              # 全屏歌词浏览与 Seek 联动 Activity / View
│   ├── PlaylistDetailActivity.kt     # 歌单详情歌曲列表页
│   ├── adapter/
│   │   ├── MusicAdapter.kt           # 统一按键焦点渲染 (focused_background) 的歌曲适配器
│   │   ├── PlaylistAdapter.kt        # 歌单列表适配器
│   │   └── TopChartAdapter.kt        # 排行榜适配器
│   └── widget/
│       ├── VinylDiskView.kt          # 自定义复古黑胶唱片旋转控件
│       └── SoftKeyBarView.kt         # 三段式软键底栏封装
└── player/
    └── PlaybackService.kt            # ExoPlayer 后台播放管理
```

### 关键代码规范约束：
1. **按键监听**：重写 `onKeyDown` 时，统一调用 `NokiaKeyBinding.fromKeyEvent(event)` 解析为语义枚举（如 `NokiaAction.SELECT`、`NokiaAction.SOFT_LEFT`、`NokiaAction.STAR`、`NokiaAction.HASH`），杜绝硬编码数值。
2. **弹窗统一**：所有选项与确认交互必须调用 `NokiaOptionsDialog.Builder(this)` 与 `NokiaConfirmDialog.Builder(this)` 构建。
3. **焦点互斥**：列表或宫格必须维护单一 `focusIndex`，在按键移动时光标自动计算平滑居中滚动（`smoothScrollToPosition`）。
