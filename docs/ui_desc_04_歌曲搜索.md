# 页面描述：KeydroidX Music — 歌曲搜索页（搜索 Tab）

> 📌 **注**：本文档为原型视觉描述（含原型示意数值）。Android Native 实际落地规范以 **`UI_DESIGN_SPEC.md`** 为准，排版字号统一采用 `keydroidx-core` 的 **`11-typography-and-font-spec.md`** 6 级 `@dimen/nokia_font_*` 语义 Token。

---

## 一、整体布局层级

页面竖向全屏布局，从上到下三个固定层：

```
┌──────────────────────────────┐  ← 顶部标题栏 (TitleBar)，固定高度 28dp
├──────────────────────────────┤
│  ┌────────────────────────┐  │
│  │  横向 Tab 导航栏 (4项) │  │  ← 紧贴内容区顶部，固定
│  └────────────────────────┘  │
│  ┌────────────────────────┐  │
│  │  搜索输入框             │  │  ← 固定在 Tab 栏正下方，约 32dp
│  └────────────────────────┘  │
│                              │
│  内容区域 (可滚动)            │  ← 分隔头 + 历史/热门词条列表
│                              │
└──────────────────────────────┘  ← 底部软键栏 (SoftKeyBar)，固定高度 26dp
```

---

## 二、各层详细描述

---

### 层 1：顶部标题栏（TitleBar）

- **位置**：屏幕最顶部，固定不滚动
- **背景**：从深蓝色渐变到藏青色（上浅下深线性渐变）
- **高度**：约 28dp

  **左侧（标题区）：**
  - Material Icon 图标：`search`（放大镜），字号 14px，白色
  - 文字标题：**"歌曲搜索"**，白色，粗体，字号 13px
  - 图标与文字水平对齐，间距 4px

  **右侧（状态区）：**
  - 信号图标：`signal_cellular_4_bar`（四格满格），灰白色，12px
  - 电量文字：**"70%"**，灰白色，11px

- **底部边缘**：1px 深黑细线

---

### 层 2：横向 Tab 导航栏（Tab Bar）

- **位置**：紧贴标题栏下方，固定
- **背景**：几乎纯黑（`#0a0e17`）
- **底部边缘**：2px 深蓝色横线
- **4 个等宽 Tab，从左到右：**

  | 顺序 | 图标 | 文字 | 状态 |
  |------|------|------|------|
  | 1 | `person` | 我的 | 未激活 |
  | 2 | `explore` | 发现 | 未激活 |
  | 3 | `leaderboard` | 榜单 | 未激活 |
  | 4 | `search` | 搜索 | **当前激活（Active）** |

  **激活 Tab（"搜索"）的视觉样式：**
  - 文字白色，粗体
  - Tab 背景有蓝色半透明渐变遮罩（约 40% 透明度）
  - Tab 底部有 2px 高、宽度 80% 的天蓝色（`#38bdf8`）高亮横线，居中

  **未激活 Tab：**
  - 图标与文字均为中灰色（`#b0b0b0`），无背景无底线

  每个 Tab：图标在上，文字在下；图标 13px，文字 11px

---

### 层 3：搜索输入框（Search Input Box）

- **位置**：Tab 导航栏正下方，紧贴，外边距 6px（上下左右各 6px）
- **背景**：深蓝黑色（`#0f172a`）
- **边框**：1px 天蓝色（`#38bdf8`），圆角 4px
- **内边距**：上下 4px，左右 8px
- **高度**：约 28dp

  **内部从左到右排列：**

  1. **搜索图标**：`search`（放大镜），天蓝色（`#38bdf8`），字号 14px
  2. **输入文字内容**：**"周杰伦"**，白色，字号 11px
  3. **光标**：紧跟文字后，为一个 6×11px 的天蓝色实心矩形，带呼吸闪烁动效（周期约 0.8s，透明度在 0 到 1 之间循环）
  4. **右侧输入法标签（Badge）**：文字 **"拼音/按键"**，半透明白底灰文字，圆角 3px，字号 9px，内边距 1px 4px；紧贴输入框右侧

## 五、焦点交互状态说明

- **焦点行（Focused Item）** 视觉变化：
  - 整行背景填充为主题焦点色（`#0055aa`）
  - 左右两侧各缩进 3px，圆角 4px
  - 底部虚线分割消失
  - 所有文字变为白色，图标变为白色
- **非焦点行**：正常样式，图标天蓝色，文字白色，底部有虚线分割
- **搜索框**：始终显示天蓝色边框（表示当前处于输入焦点状态），内含闪烁光标表示可输入
- **左软键"清空"**：清空搜索框内容及历史记录
- **中间键"搜索"**：执行搜索操作，进入搜索结果列表页
