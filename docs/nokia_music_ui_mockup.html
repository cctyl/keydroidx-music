tune 按键交互规范映射 (键盘 / 遥控器映射)

  • ↑ / ↓ 方向键：上下移动当前高亮光标 (列表/宫格/歌词)。
  • ← / → 方向键：横向切换 Tab 页签 (我的 / 发现 / 榜单 / 搜索) 或在播放页切换上/下一曲。
  • OK / Enter 键：执行确定操作（进入页面、播放选中的歌曲、播放/暂停切换）。
  • 左软键 (F1 / Q)：呼出诺基亚标准 NokiaOptionsDialog 选项菜单。
  • 右软键 (F2 / Backspace / Esc)：返回上一级或退出当前弹窗。
  • 快捷数字键：在播放页按 # 切换循环模式，按 * 切换歌词/封面。

grid_view 网易云功能在按键机上的精简与重构策略

  • 我的音乐：精简为 本地音乐、最近播放、我喜欢的音乐(496首)、创建的歌单列表。
  • 发现 / 推荐：以 2x2 宫格模块呈现“私人FM”、“每日推荐”、“歌单广场”、“排行榜”，无需复杂的手势滑动。
  • 正在播放详情：诺基亚黑胶唱片旋转动效，单行浮动歌词预览，按确定键直接暂停/播放。
  • 全屏歌词滚动：大字号点阵高亮当前行，上下键支持手动拖动与回正。
  • 搜索功能：九键输入法联动检索，历史记录快速回填。

💡 提示：您可以直接在键盘上使用 ↑ ↓ ← → 回车 Backspace 体验真实的按键机交互！
